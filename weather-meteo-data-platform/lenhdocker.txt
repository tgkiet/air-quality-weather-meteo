HƯỚNG DẪN KHỞI CHẠY HỆ THỐNG DATA PLATFORM TỪ CON SỐ 0

BƯỚC 1: KHỞI ĐỘNG HỆ THỐNG (Hạ Tầng)
Mục đích: Tải các image cần thiết và dựng lên 2 máy ảo (PostgreSQL và Airflow).
Hãy đợi khoảng 1-2 phút sau khi chạy lệnh này để Database thực sự sẵn sàng.

Lệnh chạy:
docker compose up -d --build

BƯỚC 2: NẠP DỮ LIỆU LỊCH SỬ CSV (Hà Nội 2022 - 2025)
Mục đích: Đẩy file CSV gốc của Hà Nội (~900k dòng) vào bảng dữ liệu thô (Bronze).
Thời gian chạy: Nhanh (vài giây).

Lệnh chạy:
docker exec airflow_container python3 /opt/airflow/src/scripts/load_historical_csvs.py

BƯỚC 3: KÉO DỮ LIỆU LỊCH SỬ TỪ API (Backfill)
Mục đích: Gọi API Open-Meteo để kéo dữ liệu về cho đến ngày hiện tại (21/05/2026).
Dữ liệu sẽ tự động được hợp nhất mượt mà với dữ liệu Realtime của Airflow.

[3.1] Kéo lịch sử cho 10 trạm TP.HCM (Tốn khoảng 10-15 phút):
Lệnh chạy:
docker exec airflow_container python3 /opt/airflow/src/scripts/backfill_history.py --location-prefix HCM --start-date 2022-08-02 --end-date 2026-05-21

[3.2] Kéo bù khoảng trống cho 10 trạm Hà Nội (Tốn khoảng 2-3 phút):
Lệnh chạy:
docker exec airflow_container python3 /opt/airflow/src/scripts/backfill_history.py --location-prefix HN --start-date 2025-11-30 --end-date 2026-05-21

BƯỚC 4: NHÀO NẶN DỮ LIỆU VÀ KIỂM TRA (Transform & Test)
Mục đích: Dùng dbt làm sạch dữ liệu thô, loại bỏ trùng lặp và đẩy lên tầng Gold (sẵn sàng cho Superset).

[4.1] Chạy lệnh Transform (Cờ --full-refresh giúp xây lại toàn bộ bảng):
Lệnh chạy:
docker exec airflow_container dbt run --full-refresh --project-dir /opt/airflow/dbt-transform --profiles-dir /home/airflow/.dbt

[4.2] Chạy lệnh Kiểm tra Chất lượng:
Lệnh chạy:
docker exec airflow_container dbt test --project-dir /opt/airflow/dbt-transform --profiles-dir /home/airflow/.dbt

Kết quả mong đợi: Dòng cuối cùng hiện "Done. PASS=29 WARN=0 ERROR=0 SKIP=0 TOTAL=29" là THÀNH CÔNG RỰC RỠ!

BƯỚC 5: TẬN HƯỞNG THÀNH QUẢ
Mục đích: Đăng nhập vào giao diện Airflow để kiểm tra lịch trình tự động Realtime.
Hệ thống Airflow sẽ tự động cào dữ liệu thời tiết mới mỗi giờ 1 lần từ bây giờ trở đi.

Truy cập trình duyệt:
http://localhost:8080

Username Password tự coi trong env đi má !!!
